ربط نماذج OpenCode Zen بالمنصة

دمج بوابة Zen المجانية (بدون مفتاح API) كمزوّد ذكاء اصطناعي أساسي وخيار احتياط أخير، لخدمة ترجمة المقالات ومساعد «مرشد عصب التقنية» للمحادثة.

المسار غير موثّق رسمياً حصة IP يومية بدون مفتاح API هيدر جلسة x-opencode-session

01 · نظرة عامة ومعمارية الدمج

OpenCode Zen هي بوابة استدلال مجانية توفّر اتّصالاً متوافقاً مع صيغة OpenAI (/v1/chat/completions) دون الحاجة إلى أي مفتاح API. الهوية تُنقل عبر هيدر جلسة مولّد محلياً يشبه ما يرسله تطبيق opencode الطرفي. أُدرجت البوابة في المنصة في موضعين:

ترجمة المقالات (AiTranslator)→ مزوّد أساسي «opencode»+ آخر حلقات سلسلة الاحتياط
مساعد المحادثة (AiChatAssistant)→ مزوّد قابل للاختيار+ آخر عنصر في ترتيب الاحتياط
تنبيه جوهري: الخط مُنفَّذ بمعرفة أنه مسار غير موثّق يعتمد على حصة مجانية يومية لكل عنوان IP (وليس لكل حساب/مشترك). الاستضافة المشتركة أو الـ NAT تعني أن كل المواقع على نفس IP تتقاسم الحصة. قد تُغلق البوابة أو يتغير سلوكها مستقبلاً — لذلك صُنّف المزوّد كـاحتياط أخير، بينما بقيت المزودات المسجلة بمفاتيح (Omniroute، Gemini، Groq، …) في المقدمة.

خلاصة القرار التصميمي

  • المزوّد قابل للتفعيل/التعطيل في لوحة التحكم (opencode_fallback_enabled).
  • يمكن اختياره مزوّداً أساسياً للترجمة وللمحادثة، أو اكتفاءً به كاحتياط.
  • انضبط لكل سير عمل مهلة زمنية قصيرة (20 ثانية) حتى لا يُبطئ السلسلة عند انتهاء الحصة.
  • استجابات 401 / 403 / 429 تُترجم إلى رسائل عربية واضحة عن الحصة.

02 · بوابة Zen: الاتفاقية والهيدرات

النقطة النهائية المستخدمة:

// مترجم المقالات (AiTranslator) — مسار صريح:
$endpoint = 'https://opencode.ai/zen/v1/chat/completions';

// مساعد المحادثة (AiChatAssistant) — تُضاف القاعدة تلقائياً:
callOpenAiCompat('https://opencode.ai/zen/v1', '', $model, $messages, $cfg, $extra, 20);
// دالة callOpenAiCompat تُلحق '/chat/completions' تلقائياً

رؤوس HTTP المطلوبة

لا يُرسل أي Authorization. بدلاً منه تُرسل هذه الهيدرات (نفس ما يرسله تطبيق opencode):

الهيدرالقيمةالاشتقاق
x-opencode-sessionses_ + 64 خانة hex عشوائية'ses_' . bin2hex(random_bytes(32))
x-opencode-clienttuiثابت
x-opencode-requestusr_ + 8 خانات من الجلسة'usr_' . substr($sessionId, 4, 8)
User-Agentopencode/0.1.0ثابت
Content-Typeapplication/jsonثابت

تُولّد الجلسة من جديد لكل طلب فلا تتخزّن ولا تُعاد. الصياغة الكاملة:

$sessionId = 'ses_' . bin2hex(random_bytes(32));
$headers = [
    'Content-Type: application/json',
    'x-opencode-session: '  . $sessionId,
    'x-opencode-client: tui',
    'x-opencode-request: usr_' . substr($sessionId, 4, 8),
    'User-Agent: opencode/0.1.0',
];

الطلب (payload)

متوافق مع صيغة chat.completions القياسية من OpenAI — بلا أي key:

$payload = [
    'model'       => $model,               // 'big-pickle' افتراضياً
    'messages'    => [
        ['role' => 'system', 'content' => $systemPrompt],
        ['role' => 'user',   'content' => $userPrompt],
    ],
    'temperature' => $temp,
];

الاستجابة المتوقعة

$data = json_decode($res, true);
$rawContent = $data['choices'][0]['message']['content'] ?? '';

يُجرَّد المحتوى من أي سياقات Markdown (fences ```json) إن وُجدت قبل التحليل، ثم يُحلَّل كـ JSON حسب غرض كل سير عمل (انظر الأقسام التالية).

04 · الترجمة: باقي للاحتياط والأساسي

المنطق موجود في core/AiTranslator.php — دالة translateArticle(): أولاً يُنفَّذ المزوّد الأساسي المختار، وكل فشل يملأ مصفوفة $attempts للـ diagnostics، ثم إن كان الاحتياط مفعّلاً تنسحب سلسلة احتياط مرتّبة، وفي آخرها (قبل محرك الترجمة المجاني MyMemory) يأتي opencode:

// === Step 1: المزوّد الأساسي ===
} elseif ($activeProvider === 'opencode') {
    if (($settings['opencode_fallback_enabled'] ?? '1') != '1') {
        $attempts[$activeProvider] = 'OpenCode Zen معطل في الإعدادات.';
    } else {
        $res = self::callOpencode($titleEn, $contentEn, $settings, $articleId);
        if ($res['success']) return $buildResult($res['data'], 'opencode');
        $attempts[$activeProvider] = $res['error'];
    }
}

// === Step 2: سلسلة الاحتياط — opencode قبل الأخير ===
if ($activeProvider !== 'opencode' && ($settings['opencode_fallback_enabled'] ?? '1') == '1') {
    $res = self::callOpencode($titleEn, $contentEn, $settings, $articleId);
    if ($res['success']) return $buildResult($res['data'], 'opencode');
    $attempts['fallback_opencode'] = $res['error'];
}

ترتيب سلسلة الاحتياط الفعلي للترجمة

المزوّد الأساسي (المختار)→ omniroute→ gemini→ groq→ deepseek→ openai→ custom_api→ opencode (آخر مزوّد بلا مفتاح)→ مترجم MyMemory المجاني المدمج

دالة callOpencode للترجمة

  • تأخذ العنوان الإنجليزي + محتوى المقال (مشطوباً من الوسوم، مقصوصاً حتى 3000 خانة).
  • بناء systemPrompt: إمّا من الإعداد ai_system_prompt (مع إلحاق طلب JSON)، أو نبرة «كبير محرري الأخبار التقنية» الافتراضية.
  • تطلَب الاستجابة بصيغة JSON فقط بالمفاتيح: title_ar, excerpt, content_ar, reading_time_minutes.
  • عند النجاح تُخزَّن معطيات التشخيص: mode = "opencode_{$model}" وسجل نجاح في translation_logs.
  • أي فشل يُسجَّل status=failed مع http_code و error_raw و error_summary و duration_ms.

التسجيل يعمل عبر الدالة المساعدة self::logOperation([...]) بمعرّف المقال وعنوانه ومدة الاستدعاء بالملّي ثانية.

05 · المحادثة: مرشد عصب التقنية

في core/AiChatAssistant.php يُحدَّد المزوّد النشط من إعداد ai_assistant_provider (أو ai_provider إن كانت «default»). عند الوصول إلى case 'opencode' يُنفَّذ:

private static function callOpencode(array $messages, array $cfg)
{
    $model = !empty($cfg['opencode_model']) ? $cfg['opencode_model'] : 'big-pickle';
    $sessionId = 'ses_' . bin2hex(random_bytes(32));
    $extra = [
        'x-opencode-session: '  . $sessionId,
        'x-opencode-client: tui',
        'x-opencode-request: usr_' . substr($sessionId, 4, 8),
        'User-Agent: opencode/0.1.0',
    ];
    return self::callOpenAiCompat('https://opencode.ai/zen/v1', '', $model, $messages, $cfg, $extra, 20);
}

الدالة المشتركة callOpenAiCompat($endpoint, $apiKey, $model, $messages, $cfg, $extraHeaders = [], $timeout = 45) تبني payload بلا هيدر مصادقة (لأن مفتاح Zen فارغ)، وتلحق الهيدرات الإضافية تلقائياً، وتعود باستجابة ['success', 'answer', 'provider'].

ترتيب الاحتياط في المحادثة

المزوّد النشط→ omniroute→ gemini→ openai→ groq→ deepseek→ custom_api→ opencode (الأخير)

الاختيار يستثني المزوّد النشط نفسه، ويشترط providerReady() لكل مزوّد: بالنسبة لـ opencode تفعيله يشترط أن يكون opencode_fallback_enabled == '1' (لا يتطلب أي مفاتيح). الرسالة تحتوي على سياق المقالات المنصة المرتبطة (retrieveContext) مع محفوظات آخر 8 أسطر، وقصّ الطول عند حدود آمنة (سیاق 7000، رسائل 800، سؤال 500 خانة).

09 · القيود والملاحظات الأمنية والإنتاجية

⚠️ قيود التشغيل

  • حصة لكل IP يومياً — تُشارك على الاستضافة المشتركة/الـ NAT، ليست لكل حساب.
  • مسار غير موثّق — قد يغلق أو يغيّر الاتفاقية في أي وقت؛ لذلك هو «احتياط أخير» وليس العمود الفقري.
  • لا ضمان استقرار — انتهاء الحصة يعرض أخطاء 401/403/429 أو timeout.
  • بطيء نسبياً — مهلة 20 ثانية اختيرت توازناً بين النجاح وعدم تعليق السلسلة.

أفضل الممارسات المطبّقة

  • التراجع الرقمي الآمن إلى مترجم MyMemory المجاني المدمج دائماً آخر خطوة.
  • تسجيل كل محاولة فشل في translation_logs مع الكود والمدة.
  • لا تكشف أي أسرار: لا توكن، لا key — الهوية داخل الجلسة المولّدة فقط.
  • لا تُخزَّن الجلسات؛ كل طلب بجلسة جديدة (منع إعادة استخدام الهوية).
  • مهلة صارمة بـ CONNECTTIMEOUT=10 تحمي من تعطل DNS/الشبكة.
الخلاصة: التكامل يوفر «مزوّداً بلا مفتاح» يجمع بين فائدته عند تعطّل البوابات المدفوعة، وحدودياً حاسمة في موضعه (آخر السلسلة، مهلة 20 ثانية، رسائل حصة واضحة، سجل كامل) تمنعه من أن يصبح نقطة فشل للمنصة.
