# 🚀 Universal Starter Platform & Framework Boilerplate

**Universal Starter Platform** هو قالب أساسي معياري فائق الاحترافية وقابل للتوسيع بالكامل، مبني بـ **PHP 8+ خالص (بدون أطر عمل ثقيلة أو تبعيات Composer)** و **MySQL**. صُمم ليكون نقطة البداية المثالية لبناء أي مشروع ويب، منصة SaaS، نظام إدارة محتوى، بوابة أعمال، أو متجر إلكتروني مع توفير مئات ساعات العمل البرمجية.

> 📖 **للاطلاع على دليل المطور الشامل وطريقة بناء أقسام CRUD في 60 ثانية:** [دليل المطور (DEVELOPER_GUIDE.md)](DEVELOPER_GUIDE.md)

---

## 🌟 أبرز ما يحتويه القالب

### 1. لوحة تحكم احترافية جاهزة بنسبة 100% (`/admin`)
- **تصميم متقدم وعصري:** مبنية بـ Bootstrap 5 تدعم **RTL و LTR** بالكامل، مع الوضع الداكن والفاتح (Dark/Light Mode) وحفظ الحالة فورياً.
- **قائمة جانبية ديناميكية (`config/admin_menu.php`):** إضافة أو تعديل أي قسم في لوحة التحكم في ثوانٍ عبر ملف إعدادات بسيط ومصفوفات أنيقة.
- **محرك الـ CRUD الفوري (`AdminSimpleController`):** بناء واجهات إدارة كاملة لأي جدول (قوائم، بحث، صفحات، صور، علاقات، تعديل، حذف) بكتابة مصفوفة الحقول فقط.
- **ترتيب الجداول الفوري (Universal Table Sorter):** فرز كافة الجداول فورياً من جهة المتصفح للأرقام والتواريخ والنصوص العربية والإنجليزية.
- **سجل التدقيق الشامل (Audit Logs):** تسجيل كافة العمليات مع الفروقات قبل وبعد التعديل وعنوان IP والمتصفح.
- **مركز النسخ الاحتياطي:** تصدير واستيراد قواعد البيانات وملفات JSON/CSV بضغطة زر.
- **مركز تشخيص صحة النظام (Diagnostics Hub):** فحص البيئة وقاعدة البيانات والأمان ومكتبة الوسائط.
- **لوحة إعدادات شاملة (17 مجموعة / 150 إعداداً):** إدارة الهوية، الألوان، الخطوط، مفاتيح الـ API، خوادم SMTP، وإعدادات الأمان.

### 2. محرك الذكاء الاصطناعي المركزي وسلسلة التبديل الفوري (AI Engine & Failover)
- **7 مزودين عالميين مدعومين افتراضياً:** Google Gemini (3.7 Flash/Pro)، Groq Cloud (Llama 3.3 70B)، DeepSeek (V3/R1)، OpenAI (GPT-4o/mini)، Omniroute، خوادم محلية مخصصة (Ollama / vLLM)، ومحركات مجانية بدون مفاتيح.
- **التبديل التلقائي الذكي (Auto-Failover Chain):** إذا تعطل المزود الأساسي أو انتهى رصيده، ينتقل النظام تلقائياً وبشكل غير محسوس للمزود التالي في السلسلة دون توقف التطبيق.
- **مساعد ذكي وشات بوت تفاعلي (AI Chatbot with RAG):** بحث في محتوى المشروع للإجابة على استفسارات الزوار مع نظام حصص يومية (Daily Quotas) وشحن رصيد إضافي (Boosts).

### 3. منظومة أمان متكاملة (Enterprise-Grade Security)
- **جدار الحماية الفوري (SecurityGuard IDS):** فحص وتحليل كافة الطلبات لحظر محاولات حقن SQL، XSS، وعبور المسارات، مع تنبيهات أمنية فورية.
- **حماية CSRF و Rate Limiting:** منع الهجمات الموجهة ومحاولات التخمين على تسجيل الدخول.
- **رادار الزوار والعناكب (Traffic Radar):** رصد وتصنيف الزوار والبوتات وعناكب محركات البحث وقياس سرعة استجابة الخادم.

### 4. منظومة الإعلانات والأرباح (Monetization Suite)
- **إدارة الإعلانات (`/admin/ads`):** دعم البنرات الصورية، شبكات الإعلانات (Google AdSense / Adsterra / Ezoic)، والروابط التسويقية (Affiliate Smartlinks).
- **حقن ذكي للإعلانات:** أعلى الهيدر، بين المقالات، داخل نص المقال، والشريط الجانبي.
- **ملف `ads.txt` ديناميكي:** متوافق مع معايير IAB لمحركات الإعلانات.

### 5. أدوات المطور ومعالج التثبيت
- **أداة Craft CLI:** تشغيل الخادم المحلي وتوليد النماذج والمتحكمات والـ APIs بنقرة زر (`php craft serve`, `php craft make:crud`, `php craft make:controller`, `php craft doctor`).
- **معالج التثبيت الرسومي (`install.php`):** تجهيز وربط قاعدة البيانات وإنشاء الجداول وحساب المدير في 30 ثانية.
- **واجهة برمجة تطبيقات جاهزة (REST API v1):** نظام مصادقة بالمفاتيح (API Keys)، تحديد نطاقات الوصول (Scopes)، ومعدل الطلبات.

## 🚀 البدء السريع

### 1. التثبيت عبر المتصفح:
افتح المتصفح وانتقل إلى:
```
http://localhost/install.php
```

### 2. أو تشغيل الخادم المحلي عبر أداة Craft:
```bash
php craft serve
```

ثم افتح لوحة التحكم على: `http://127.0.0.1:8000/admin`  
- **اسم المستخدم:** `admin`  
- **كلمة المرور:** `Admin@123456`

## 🛠️ خريطة أوامر Craft CLI

| الأمر | الوظيفة |
| :--- | :--- |
| `php craft serve [host:port]` | تشغيل خادم التطوير المحلي المدمج |
| `php craft doctor` | فحص متطلبات النظام والبيئة وقاعدة البيانات |
| `php craft make:crud <Resource>` | توليد قسم ولوحة إدارة CRUD كاملة لجدول معين |
| `php craft make:controller <Name>` | إنشاء متحكم جديد للواجهة العامة |
| `php craft make:api <Name>` | إنشاء متحكم REST API v1 مؤمن |
| `php craft make:model <Name>` | إنشاء نموذج بيانات (Model) جديد |
| `php craft ai:test [provider]` | فحص واختبار سرعة واستجابة مزود الذكاء الاصطناعي |
