# منصة الأخبار التقنية — Tech News Platform

منصة إخبارية تقنية متكاملة باللغة العربية، مبنية بـ **PHP خالص (بدون إطار عمل)** و **MySQL**، تعمل على الاستضافات المشتركة (موثّقة على InfinityFree). تجمع المنصة الأخبار تلقائياً من خلاصات RSS عالمية، وتترجمها وتصنّفها وتنشرها عبر سير عمل آلي، مع لوحة تحكم عربية كاملة، وواجهة زائر مخصصة PWA، وواجهة برمجة REST API.

> وثائق إضافية: [دليل SEO](docs/SEO_GUIDE.md) • [دليل تحقيق الدخل بالإعلانات](docs/ADS_MONETIZATION_GUIDE.md)

## 🌟 أبرز المزايا

### للزائر (الواجهة العامة)
- **الرئيسية**: خبر رئيسي (Hero)، أقسام، أخبار عاجلة (Breaking)، الأكثر قراءة، موجز جانبي، ووضع ليلي.
- **قارئ المقالات**: طباعة مريحة، شريط تقدم القراءة، تفاعلات (إعجاب/فيديو مذهل/مضحك)، تعليقات، حِفظ للمفضلة، مشاركة، أخبار ذات صلة.
- **محرك بحث** فوري مع اقتراحات، **تصنيفات**، **أرشيف شهري**، **سلاسل مقالات (Series)** و**قصص (Stories)**.
- **Live Blog** بتحديث مباشر، **دروس تقنية خطوة بخطوة** مع وسائط، **استطلاعات رأي**، **نشرة بريدية**، صفحة اتصل بنا.
- **PWA**: Service Worker + Manifest — تعمل دون اتصال (Offline) وInstalable، مع **إشعارات Push** للمتصفحات الداعمة.
- **SEO**: بيانات Open Graph / Twitter Cards، **JSON-LD (المقالة)**, `sitemap.xml`، وخلاصات **RSS / Atom** (بما يخدم Google News).

### للطبعة (لوحة التحكم `/admin`)
- **لوحة معلومات** بإحصائيات لحظية (مقالات، زيارات، تعليقات، أنشطة، أداء الكرون).
- **إدارة متكاملة**: مقالات (كتابة/تعديل/معاينة)، تصنيفات، وسائط، تعليقات وتعديلها، مستخدمون وأدوار، صفحات ومحتوى ثابت، قوائم.
- **استوديو تجميع الأخبار (Aggregator)**: جلب الخلاصة ومعاينة العناصر، عرض حالة كل عنصر (منشور / مسودة / جديد لم يُنشر)، **نشر AJAX فوري** دون إعادة تحميل (دفعة واحدة أو متعددة).
- **إدارة مصادر RSS**: إضافة/تعديل، **فحص صحة الخلاصات** (Health Check) بالدفعات، **عدّاد الأخبار الجديدة غير المنشورة** لكل مصدر (`new_items_count` / `new_items_last_at`)، اقتراحات بدائل للخلاصة المعطوبة.
- **الترجمة بالذكاء الاصطناعي**: قاموس تقني عربي متخصص + محركات AI، مع **سجل الترجمة** وتفاصيل الأخطاء.
- **التصنيف الآلي** بذكاء (CategoryClassifier) بقواعد قابلة للتحرير من اللوحة.
- **Live Blog و Polls وتاريخ النشر** بإدارة كاملة.
- **التحليل والإحصاء**: Analytics + **رادار الزيارات والبوتات (Traffic Radar)**.
- **الأمان**: تنبيهات أمنية، **سجل الأنشطة (Audit Log)**، مفاتيح API، تشخيصات النظام.
- **النسخ الاحتياطي**: تصدير/استيراد قاعدة البيانات، المقالات، الإعدادات، القواعد، الرسائل، الاشتراكات وغيرها.
- **الكرون**: لوحة تشغيل يدوي + سجل التنفيذ وتفاصيله.

### الأتمتة والاستيراد
- **`cron/rss_auto_publish.php`**: يجلب كل مصادر RSS، يفحص التكرار، يترجم ويعيد الكاتب تلقائياً بالـ AI، يصنّف المقالة، ويحدّث عدّاد الجديد لكل مصدر.
- **`cron/archive_old_news.php`**: أرشفة الأخبار القديمة تلقائياً.
- **FeedFetcher**: جلب قوي عبر cURL مع تناوب وكلاء المستخدم، معالجات الأخطاء، كشط احتياطي لصفحات HTML غير المستجيبة `RSS`.

### واجهة برمجة التطبيقات (API)
- واجهة JSON عامة: مقالات، تعليقات، إشعارات.
- **REST API v1** (`/api/v1`) مسجّلة وموثقة: مقالات، تصنيفات، دروس، إحصاءات، مزوّد RSS، **نقطة AI (تلخيص/ترجمة)**، وبيانات السوق (Market Pulse).

## 🧱 التقنيات والبنية

- **اللغة**: PHP 8.x (بدون Composer، بدون تبعيات خارجية).
- **قاعدة البيانات**: MySQL / MariaDB (UTF-8 `utf8mb4`).
- **الواجهات**: قالب عام مخصص (HTML/CSS/JS خام)، لوحة تحكم **Bootstrap 5 RTL**.
- **التخزين الزمني**: مركزي — تُخزَّن التواريخ والطوابع بـ **UTC** وينتهي `Database::query` بـ `SET time_zone='+00:00'`، بينما تُعرض عبر دوال مثل `fmt_date()` / `site_dt()` بتوقيت موقع المنصة (من الإعدادات، افتراضياً `Asia/Riyadh`). ملفات JSON-LD/Sitemap/RSS تبقى بتوقيت UTC المطلق (صحيحة لمحركات البحث).
- **الأمان**: `SecurityGuard` (كشف ومحاولة حظر SQLi/XSS/عبور المسارات/الماسحات عند كل طلب + تنبيه المشرفين)، توكنات **CSRF** في كل النماذج، تجزئة كلمات السر، **Rate Limiting** لتسجيل الدخول، تعقيم وتحقق المدخلات، تحقق MIME للرفع، صلاحيات حسب الدور، سجل أنشطة شامل.

## 🚀 التشغيل محلياً (XAMPP)

1. انسخ المشروع إلى `C:\xampp\htdocs\tech-news-platform`.
2. أنشئ قاعدة `tech_news_db` واستورد مخطط القاعدة:
   - `install.sql` (هيكل كامل) — أو `schema.sql` / `database_schema.sql`.
   - طبّق مهاجرات إضافية في الجذر إن وجدت، مثل `migrate_rss_new_items_count.sql`.
3. تأكد من قيم الاتصال في `config/database.php` (المنطق: `config/hosting.php` → متغيرات بيئة → افتراضيات محلية `root` بدون كلمة سر).
4. شغّل الخادم:
   - من ملف `run-windows.bat` أو `run-windows.ps1`، أو يدوياً:
     ```powershell
     php -S 127.0.0.1:8000 router_local.php
     ```
   - أو امنح المجلد إلى Apache ثم افتح `http://localhost/tech-news-platform/`.
5. تفضل إلى `/admin` لبدء الاستخدام (المستخدم الأول أُنشئ أثناء الإعداد).

> ملاحظة: `run.sh` لبيئات Unix/Linux.

## ☁️ النشر على الاستضافة المشتركة

1. انسخ الملفات إلى `htdocs` وعدّل `config/database.php` الملفات أو أنشئ `config/hosting.php` من نموذج `config/hosting.example.php` (الملف يُتجاهل في Git — لا يُرفَع للنسخ الاحتياطي).
2. استورد `install.sql` وطبّق أي مهاجرات يدوياً عبر phpMyAdmin (المخطط **لا يُنشر تلقائياً**).
3. فعّل **Cron Jobs** عند المزود:
   - **كل ساعة**: `php cron/rss_auto_publish.php` (أو HTTP: `https://domain/cron/rss_auto_publish.php?secret=CRON_SECRET`).
   - **يومياً**: `php cron/archive_old_news.php`.
4. التسليم عبر **GitHub Actions** (`.github/workflows/deploy.yml`) عند كل push إلى `main` مع الأسرار:
   `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_SERVER_DIR`.
   - رفع تفاضلي للملفات المتغيرة فقط، لا يُحذف شيء على الخادم، و`config/hosting.php` و`uploads/*` مستثناة.

## ⚙️ الميزات التشغيلية المؤكدة مؤخراً

- **عدّاد "جديد لم يُنشر"**: عمودا `rss_sources.new_items_count` و `new_items_last_at` يُحدَّثان عند كل جلب فعلي (استوديو أو كرون) بعدد الأخبار الواصلة عبر الخلاصة وغير المنشورة، مع شارة في لوحة المصادر وشارة على بطاقة الاستوديو.
- **فحص صحة الخلاصات كاملاً على الاستضافات المحدودة**: ميزانية زمنية 10 ث لكل طلب (يعالج مصدراً واحداً على الأقل ثم يتابع الدفعات عبر `offset/limit`)، مهلة عليا لغاية 15 ث للفحص المفرد، وإرجاع JSON كامل قبل مهلة PHP.
- **عرض الزمن**: كل تواريخ اللوحة والموقع تُعرض بتوقيت الموقع (3 ساعات إن كانت المنطقة الرياض) بدل UTC الخام، بينما تبقى التواريخ القياسية (Sitemap/JSON-LD/RSS) UTC.
